# Implementation Plan: DataSphere Platform Baseline

**Branch**: `001-platform-baseline` | **Date**: 2026-10-19 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `/specs/001-platform-baseline/spec.md`

## Summary

Establish and validate the architectural baseline for DataSphere, a high-performance modern database management application for Windows desktop built on .NET 10, WPF, `Wpf.Ui` Fluent Design 2, Clean MVVM (`CommunityToolkit.Mvvm`), and `MySqlConnector`. This feature delivers an end-to-end operational shell featuring single-instance lifecycle enforcement, secure encrypted credential management, non-blocking asynchronous database connectivity testing, schema exploration, dynamic theme synchronization, and 100% technical English documentation.

## Technical Context

**Language/Version**: C# (LangVersion `preview`), .NET 10 (`net10.0-windows7.0`)

**Primary Dependencies**: `Wpf.Ui` (Fluent Design 2 controls & navigation), `CommunityToolkit.Mvvm` (v8.4.2), `Microsoft.Extensions.Hosting` (v10.0.0), `MySqlConnector` (v2.4.0), `System.IO.Hashing` (v10.0.0)

**Storage**: Local encrypted JSON storage (`PasswordEncryptor` with Windows DPAPI / AES-GCM) for connection profiles; remote MySQL/MariaDB server connections

**Testing**: MSTest / xUnit for unit and contract verification; PowerShell automated smoke and build verification

**Target Platform**: Windows 10 (1809+) and Windows 11 (x64)

**Project Type**: Windows Desktop Application (WPF Native)

**Performance Goals**: UI frame rate at 60 FPS (<16ms per frame); application cold launch < 2.0s; single-instance focus signal < 500ms; zero UI thread freezing

**Constraints**: Strict Clean MVVM separation (ViewModels MUST NOT import `System.Windows.*`); zero business logic in Code-Behind (`*.xaml.cs`); 100% US English XML doc comments on all code symbols; parameterized SQL queries only; zero plain-text passwords on disk or logs

**Scale/Scope**: Single client instance managing multiple MySQL/MariaDB connection profiles and introspecting extensive schema hierarchies
